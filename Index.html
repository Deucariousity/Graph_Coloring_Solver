Graph Coloring Solver

List the things that cannot go together. This finds the fewest groups (tanks, traffic phases, exam slots, map colors) that keep every conflicting pair apart.

Problem

    How to write the problem
    • One item per line, followed by a colon and the items it conflicts with: F1: F2, F3, F4
    • Or one pair per line: A-B, A,B or A B
    • A name on its own line adds an item with no conflicts.
    • You only need to list each conflict once. Lines starting with # are notes.
    • Names cannot contain spaces, commas, colons or hyphens. Up to 120 items.
    • You can also edit the graph directly: turn on Edit, click empty space to add an item, and click two items to add or remove a conflict.
